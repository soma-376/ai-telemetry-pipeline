# 0003. 값이 없으면 0 이 아니라 None 으로 남긴다

## Status

Accepted

## Context

"0건" 과 "측정 불가" 는 다른 사실이다. Codex 는 커밋/PR/변경 라인 수를 **측정할 수 없고**,
벤더마다 보고하지 않는 필드가 다르다. 결측을 0 으로 채우면 대시보드는
"Codex 사용자는 커밋을 하나도 안 했다" 는 거짓을 그린다.
집계 단계에서는 결측과 0 을 더 이상 구분할 수 없으므로, 구분은 정규화 시점에만 가능하다.

## Decision

- 측정 불가·미보고 값은 **`None` 으로 남긴다.** 0 은 실제로 0 이 관측된 경우에만 쓴다.
- 어댑터는 벤더가 주지 않는 필드를 기본값으로 채우지 않는다.

## Alternatives

### A. 결측을 0 으로 채운다
- 장점: 다운스트림의 NULL 처리 부담이 없다.
- 단점: 결측과 0 이 합쳐져 지표가 왜곡된다.
- 탈락 이유: 대시보드가 측정 불가를 "0 건" 으로 보여주게 된다.

### B. 결측 표시용 sentinel 값(-1 등)을 쓴다
- 장점: 스키마 타입이 단순해진다.
- 단점: 합산·평균에 섞이는 순간 조용히 오염된다.
- 탈락 이유: NULL 이 표준적이고 안전하다.

## Consequences/Tradeoffs

### Positive
- "측정 불가" 가 데이터에 사실 그대로 남아 집계 정확성이 보존된다.

### Negative
- 다운스트림 쿼리가 NULL 을 명시적으로 다뤄야 한다.
